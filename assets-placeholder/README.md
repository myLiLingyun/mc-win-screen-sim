# Generated placeholder assets

These files are a minimal, original fallback so the player can run without any
Minecraft assets:

- 16x16-style procedural end sky/portal/vignette textures;
- a simple generated `MINECRAFT` logo and `JAVA EDITION` subtitle;
- small GLSL 330 shaders written for this project;
- a printable-ASCII bitmap font generated from the CC0 Aileron font bundled
  with Pillow (no font software is included).

They are **not** Minecraft's Mojangles font, Unifont, shaders or textures.
Files placed in `../assets/` take precedence over these fallbacks.
