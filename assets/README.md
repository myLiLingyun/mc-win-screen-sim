# User assets

This directory intentionally contains only the public-domain English text.
Place a full Minecraft 26.2 asset tree here **only if you have the right to use
it**; every file present here overrides the matching placeholder in
`../assets-placeholder/`. Do not commit proprietary assets to the repository.

Expected paths:

```text
end_poem_en.txt
end_poem_zh.txt
end_poem_lzh_shang.txt
end_poem_lzh_wang.txt
end_poem_lzh_fang.txt
end_poem_lzh_ice.txt
font/default.json
font/include/default.json
font/include/space.json
font/include/unifont.json
font/*.png
font/unifont.zip
shaders/core/*.vsh
shaders/core/*.fsh
shaders/include/*.glsl
textures/end_sky.png
textures/end_portal.png
textures/credits_vignette.png
textures/minecraft.png
textures/edition.png
textures/pack.png
sounds/alpha.ogg
```

The text files must be 151 lines and line-aligned with the English text. The
program checks for each file independently, so partial overrides are allowed.

them from this repository without complying with that license.
